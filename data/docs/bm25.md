# BM25 lexical ranking

BM25 (Best Matching 25) is a bag-of-words ranking function from the probabilistic relevance
framework. It scores a document against a query by summing a contribution for each query
term that the document contains. It needs no training and no model, only token statistics
gathered from the corpus.

## The scoring formula

Each term contributes its inverse document frequency (IDF) multiplied by a saturated term
frequency. IDF rewards rare terms: a word that appears in almost every document carries
little signal, while a word found in only a handful of documents carries a lot.

Term frequency saturation is controlled by the parameter `k1`, usually set between 1.2 and
2.0. With saturation, the tenth occurrence of a word adds much less than the first, so a
document cannot win simply by repeating a term.

Length normalisation is controlled by the parameter `b`, usually 0.75. A long document
naturally contains more term occurrences, so BM25 divides the term frequency by the
document length relative to the average length. Setting `b` to 0 disables length
normalisation entirely; setting it to 1 applies it fully.

## Tokenisation matters

BM25 only matches tokens exactly. The tokenizer decides whether `Retriever` matches
`retriever`, whether `top_k` is one token or two, and whether stop words such as "the" are
counted. Lowercasing and splitting on non-alphanumeric characters is a reasonable default
for English technical text.

## Where BM25 is strong

Because it matches surface forms, BM25 excels at queries that contain identifiers, product
codes, error messages, acronyms and rare proper nouns. It struggles with paraphrases: a
query about "car" will not match a passage that only says "automobile". Combining BM25 with
dense retrieval gives a hybrid retriever that handles both cases.
